# CONTENT-EDITORIAL-001 — Model-assisted editorial content policy

Status: DECIDED

M99 may use a language model to draft Product Name, H1, H2/H3/H4/H5 structure,
Short Description, Long Description, Meta Title, Meta Description, FAQ and ALT,
but the model is never the source of product truth.

Pipeline:
Verified canonical knowledge -> search-intent/content plan -> model draft ->
editorial rewrite -> evidence/claim validation -> similarity/boilerplate checks ->
language review -> operator preview -> channel payload.

Passing or evading an AI detector is NOT a quality target. The target is useful,
original, non-template, evidence-grounded content.

H1 is unique. H2-H5 are used only when semantically useful; headings are not
manufactured merely to satisfy a numeric SEO template.

Mandatory gates:
- factual evidence coverage;
- SEO/search-intent fit;
- boilerplate similarity;
- cross-product/catalogue similarity;
- language naturalness;
- Meta Description vs Short Description distinctness;
- unsupported-claim blocking.

AI may draft/edit. MPN, supplier reference, EAN/GTIN, materials, standards,
stock/availability and certifications must come from verified evidence.
